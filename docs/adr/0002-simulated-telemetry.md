# ADR-0002：内置电网仿真数据源

- 状态：已采纳
- 日期：2026-10-26

## 背景

课程作业没有真实 SCADA 或 Modbus 设备。若使用随机数生成数据，曲线会杂乱无章，越限告警也会随机出现，既无法体现电力业务规律，也不利于演示。

## 决策

实现 `TelemetrySimulator` 作为默认数据源：

- 负荷跟随典型日曲线（早晚双峰），采用一阶惯性平滑；
- 频率具备一次调频特性，电压随负荷轻微下降；
- 电流由功率反算，功率再由取整后的 U、I、cosφ 计算，三个字段天然自洽；
- 提供固定随机种子，测试可完全复现；
- 支持注入四类扰动，用于告警演练。

数据源通过 `ITelemetrySource` 抽象，真实接入时替换实现即可，界面与监控管线无需修改。

## 结果

- 演示数据具有物理意义，趋势曲线平滑、告警可解释。
- 单元测试可以断言“功率 ≈ √3·U·I·cosφ”，保证公式实现正确。
- 局限：无法验证真实协议（Modbus/OPC UA）的解析与断线重连，这些留作扩展点。

## 备选方案

- **纯随机数**：实现最快，但曲线与告警缺乏业务含义。
- **录制回放**：真实感强，但需要外部数据文件，且无法演示实时扰动。
- **连接真实设备**：课程环境不具备条件。
