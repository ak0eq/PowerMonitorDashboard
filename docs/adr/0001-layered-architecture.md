# ADR-0001：分层架构与 MVVM

- 状态：已采纳
- 日期：2026-10-26

## 背景

作业要求实现一个大屏监控程序，涉及数据模型、校验、告警、动画、视频与持久化。若全部写在 `MainWindow.xaml.cs` 中，规则无法测试、界面改版会牵动业务逻辑，也不利于讲解 MVVM。

## 决策

拆分为两个项目：

- `PowerMonitorDashboard.Core`：领域模型、校验、告警状态机、仿真、历史缓冲与导出，不依赖 WPF。
- `PowerMonitorDashboard.App`：视图、视图模型、主题、基础设施与组合根。

依赖方向固定为 `App → Core`。视图模型通过构造函数接收接口（日志、时钟、调度器、对话框），由 `AppHost` 在启动时装配。

## 结果

- 核心规则可用普通 xUnit 测试覆盖（113 个 Core 测试）。
- 界面可在不触碰业务规则的前提下重构。
- 代价是需要维护两套项目与更多接口，但对本项目的规模而言收益更大。

## 备选方案

- **单项目 + 文件夹分层**：更简单，但无法从编译期阻止 UI 依赖泄漏到规则层。
- **引入 Prism / CommunityToolkit.Mvvm**：减少样板代码，但引入第三方依赖；本项目自实现 `ObservableObject`、`RelayCommand` 与 `ViewModelBase`，教学价值更高。
