# 数据模型与业务规则

## 1. 单位与公式

| 量 | 符号 | 单位 | 说明 |
| --- | --- | --- | --- |
| 线电压 | U | kV | 三相线电压有效值 |
| 线电流 | I | A | 三相线电流有效值 |
| 视在功率 | S | MVA | `S = √3 × U(kV) × I(A) / 1000` |
| 有功功率 | P | MW | `P = S × cosφ` |
| 频率 | f | Hz | 电网频率 |
| 电量 | E | MWh | 按梯形法对功率积分 |

反算电流：`I = P × 1000 / (√3 × U × cosφ)`。

仿真器与人工录入的跨字段校验共用 `PowerMath`，保证全系统只有一套公式。

## 2. 领域模型

### 2.1 PowerReading

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `Id` | `Guid` | 数据点标识 |
| `Timestamp` | `DateTimeOffset` | 采样时间，带时区 |
| `VoltageKv` | `double` | 电压，1 位小数 |
| `CurrentA` | `double` | 电流，整数 |
| `PowerMw` | `double` | 有功功率，2 位小数 |
| `FrequencyHz` | `double` | 频率，2 位小数 |
| `Source` | `ReadingSource` | 仿真 / 人工 / 导入 / 回放 |
| `Quality` | `QualityFlag` | Good / Uncertain / Bad |

计算属性：`ApparentPowerMva`、`PowerFactor`、`DateText`、`TimeText`、`VoltageText` 等。对象实现 `INotifyPropertyChanged`，数值变化时同时通知依赖属性；`UpdateFrom` 用于实时卡片就地刷新，`Clone` 用于历史快照。

### 2.2 PowerThresholds（默认值）

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `NominalVoltageKv` | 220 | 标称电压 |
| `VoltageAttentionRatio` | 5% | 电压注意区间 ±5% |
| `VoltageCriticalRatio` | 10% | 电压严重区间 ±10% |
| `FrequencyAttentionLowHz` / `HighHz` | 49.5 / 50.5 | 频率告警带 |
| `FrequencyCriticalLowHz` / `HighHz` | 49.0 / 51.0 | 频率严重带 |
| `CurrentAttentionA` / `CriticalA` | 1350 / 1550 | 电流告警 / 严重 |
| `PowerAttentionMw` / `CriticalMw` | 500 / 540 | 功率告警 / 严重 |
| `PowerBandHighMw` / `LowMw` | 400 / 250 | 负荷“高/中/低”分界 |
| `InstalledCapacityMw` | 750 | 负荷率分母 |

阈值可在“设置”对话框中在线修改，修改后立即影响状态评估、告警与图表参考线。

## 3. 校验规则

| 字段 | 规则 | 错误提示 |
| --- | --- | --- |
| 电压 | 必填；0～500 kV；最多 1 位小数 | “电压应在 0～500 kV 之间”“电压最多保留一位小数” |
| 电流 | 必填；0～5000 A | “电流应在 0～5000 A 之间” |
| 频率 | 必填；47.0～52.0 Hz | “频率应在 47.0～52.0 Hz 之间” |
| 时间戳 | `yyyy-MM-dd HH:mm:ss`（兼容 `yyyy-MM-dd HH:mm` 等）；不得晚于当前时间 | “时间格式应为 yyyy-MM-dd HH:mm:ss”“时间戳不能晚于当前时间” |
| 功率 | 可留空；0～1000 MW | 留空时按功率因数自动计算 |
| 跨字段 | `|P − √3·U·I·cosφ/1000| > max(5 MW, 10%)` | 非阻断警告，提示估算值 |

校验结果分为 `Error`（阻断）与 `Warning`（可保存但提醒）。WPF 的 `ValidationRule` 与保存前的整体校验调用同一套 Core 函数。

## 4. 告警模型

### 4.1 生命周期

```
           ┌──────────── 工况恢复（带回差） ────────────┐
           ▼                                           │
      [ Cleared ] ◄──────────────┐                     │
                                 │                     │
 越限 ──► [ Active ] ── 值班员确认 ──► [ Acknowledged ] ┘
              │
              └── 越过严重阈值 ──► 级别升级（仍为同一条告警）
```

- 同一 `AlarmKind` 只保留一条活动告警，避免重复刷屏。
- 升级只改变 `Severity` 与描述，不产生新告警。
- 确认不改变工况判断；工况恢复后自动清除并记录清除时间。

### 4.2 回差（Hysteresis）

举例：频率上限告警 50.5 Hz，回差 0.05 Hz。

```
50.62 → 产生告警
50.46 → 仍保持（> 50.45）
50.42 → 自动清除（≤ 50.45）
```

若没有回差，数据在 50.5 附近抖动会不断产生/清除告警，形成告警风暴。

## 5. 仿真模型

- **日负荷曲线**：控制点（0 时 0.55、4 时 0.48、10 时 0.86、19 时 0.94、21 时 0.97、24 时 0.55），余弦插值。
- **负荷惯性**：`load ← load + (target − load) × (1 − e^(−Δt/30)) + 噪声`。
- **频率**：`f = 50 + droop(load) + OU 噪声 + 扰动`，时间常数 8 s。
- **电压**：`U = 220 × (1 + 0.012 × (0.85 − loadRatio)) + 噪声 + 扰动`，时间常数 12 s。
- **功率自洽**：先对 U 取 1 位小数、由 P 反算 I 并取整，再用取整后的 U、I 与 cosφ 计算最终 P。
- **扰动**：频率上扰/下扰 ±0.62 Hz × 幅度、电压暂降 −11 kV × 幅度、负荷冲击 +9% × 幅度，按 6 s 指数衰减。

## 6. 历史与导出

- 内存环形缓冲：默认 5000 条；退出时保存最近 5000 条到 `history.json`。
- 表格显示上限默认 500 行，支持“仅异常”筛选与自动滚动。
- CSV 列：序号、采样时间、电压、电流、有功功率、频率、视在功率、功率因数、负荷等级、运行状态、数据来源、数据质量。
- 告警 CSV 列：序号、产生时间、级别、类型、描述、状态、确认时间、清除时间。
- 文件使用带 BOM 的 UTF-8，Excel 直接打开不乱码。

## 7. 数据质量

`QualityFlag` 预留了工业采集语义：

- `Good`：数据可信；
- `Uncertain`：可疑（例如采集延迟、量程临界）；
- `Bad`：不可用，状态评估会降级为“注意”。

当前仿真源始终产生 `Good`，为后续接入真实数据源保留扩展点。
